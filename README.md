# Romina Pitronello

Psicometrista. Diseño instrumentos para medir lo que no se ve directamente: estudiantes, trabajadores y, desde 2026, instancias de modelos de lenguaje.

Dirijo sistemas de agentes de IA. Las specs y los prompts son míos; el código lo escriben instancias de Claude y yo verifico contra el código. Eso corre en producción en [PasaElFiltro SpA](https://pasaelfiltro.cl): pipeline de agentes sobre la API de Anthropic, servidores MCP con OAuth, function calling, orquestación multi-modelo (Opus, Sonnet, Haiku, Fable) y gobernanza escrita — permisos declarados por agente, mínimo privilegio para agentes de otro proveedor, inspección de prompt injection.
